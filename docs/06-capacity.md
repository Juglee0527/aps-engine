# Capacity Planning

## 1. 현재 범위

첫 CAPA 단계는 설비별 반복 주간 근무시간을 기준으로 기간 가용시간을 계산합니다.

```text
Machine
  → Weekly Working Calendar
    → 요청 기간의 실제 가용 구간
      → 총 가용 분
```

공휴일, 계획 정비, 휴게시간 예외와 교대조 캘린더는 아직 포함하지 않습니다.

## 2. WorkingCalendar 규칙

- 요일과 시작·종료시각으로 반복 주간 근무시간을 정의합니다.
- 종료시각은 시작시각보다 이후여야 합니다.
- 자정을 넘는 시간대는 첫 MVP에서 허용하지 않습니다.
- 같은 설비와 요일의 시간대는 서로 겹칠 수 없습니다.
- `INACTIVE` 설비에는 신규 캘린더를 등록할 수 없습니다.

## 3. 가용시간 계산

`WorkingTimeCalculator`는 주간 규칙과 요청의 고정 UTC offset을 사용합니다.

- 조회 구간 밖의 근무시간은 경계에서 잘라냅니다.
- 여러 근무일에 걸친 총 가용 분을 합산합니다.
- 작업시간이 하루 근무시간을 넘으면 다음 근무일로 이어서 종료시각을 계산합니다.
- 주말과 비근무시간은 작업시간에 포함하지 않습니다.
- 무한 탐색을 방지하기 위해 최대 10년까지만 작업 배정을 탐색합니다.

## 4. 제한사항

첫 구현은 한국 표준시처럼 DST 변경이 없는 고정 offset 사용을 전제로 합니다.
지역별 DST가 필요한 시점에는 `ZoneId` 기반 캘린더로 확장해야 합니다.
